# アイカツ！アンコール 取扱店舗の見張り

公式サイトの[取扱店舗](https://dcd.aikatsu.com/encore/shoplist/)で、決めた地域の店の「台ごとの最終更新」を見張り、意味のある更新だけを Discord に知らせます。
GitHub Actions で 10 分おきに動きます（GitHub の都合で数分〜20 分ほど遅れることがあります）。PC を切っていても動きます。

最終更新は、筐体が通信すると変わります（開店の電源の立ち上げ、カード切れなどのエラー、入荷して稼働を始めたときなど）。在庫や稼働の証明ではないので、通知文では断定しません。
台のデータがない店（最終更新から 3 日ほどたった店など）は、公式サイトの検索に出なくなります。戻ってきたら「復活」として知らせます。

## 届く通知（見出し「公式更新ウォッチ（HH:MM時点）」の 1 通にまとめる）
| 印 | いつ |
|---|---|
| 🟢 | 台の最終更新が、前回から 36 時間以上たって新しくなった |
| 🔁 | 一覧から消えていた店が、新しい最終更新で戻ってきた（台データ復活） |
| 🆕 | 見張っている地域に、見張り始めてから初めて載った店（台データ新規掲載） |
| ➕ | 台が増えた |
| ⚠️ / ✅ | 公式サイトを 1 時間読めない状態が続いた／読めるようになった |

- 短い間隔の更新、台が消えた、店が一覧から消えた、は知らせず `history.csv` に書くだけ。
- 夜（22 時〜8 時）は調べて記録しますが、通知はためておき、朝 8 時すぎに 1 通で送ります。
- 一覧から消えたとみなすのは、続けて 3 回（約 30 分）出なかったとき。一時的な表示の乱れで「復活」を誤って知らせないためです。最終更新が前と同じまま戻ったときも知らせません。

何時間ぶりで知らせるか（`MIN_GAP_HOURS`）、夜の時間帯（`QUIET_START`、`QUIET_END`）は `.github/workflows/watch.yml` で変えられます。

## 設定（GitHub の Settings → Secrets and variables → Actions → Secrets）
| 名前 | 中身 |
|---|---|
| `DISCORD_WEBHOOK_URL` | Discord のウェブフックの URL |
| `STORES` | 見張る店名や地名。1 行に 1 つ。公式サイトの検索欄と同じで、店名や住所の一部でも探せる（完全に同じ名前の店があればその店だけ）。「愛知県小牧市」のように県名で始めると、その県だけで探す（苫小牧市などを除ける） |

店名は Secrets に入れるので、公開リポジトリのログには出ません。`state.json` と `history.csv` にも店名は書かず、ハッシュだけを書きます。
`STORES` に新しく加えた地域は、その回の店を基準として記録し、「見張りに加えました」を送ります（その地域の店はこの回は 🆕 にしない）。

## 動作確認
Actions タブ →「取扱店舗の最終更新を見張る」→「Run workflow」。チェックを入れたままだと、変化がなくても今の最終更新が Discord に届きます。

## この PC で試す（Discord には送らない）
```bash
DRY_RUN=1 STATE_FILE=test_state.json HISTORY_FILE=test_history.csv STORES="愛知県一宮市" py -3 -X utf8 watch.py
```
`FAKE_NOW="2026-11-25 23:00"` を付けると、その時刻として動きます（夜のためおきの確認用）。

## 注意
- 公開リポジトリは無料で何回でも動かせます（非公開だと月の無料枠を超えます）。
- 60 日間リポジトリに更新がないと定期実行が止まりますが、最終更新が変わるたびに `state.json` を保存するので、普段は止まりません。止まったら Actions タブで有効にし直します。
